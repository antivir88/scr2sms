# SCR → SMS

`scr2sms.py` собирает обычный многобанковый SMS ROM из экранов ZX Spectrum
`256×192` (`.scr`, ровно 6912 байта):

```bash
python3 tools/scr2sms.py ~/.clonesms/screens -o spectrum-album.sms
```

ROM использует стандартный Sega mapper. Каждый экран получает отдельный банк
16 KiB; первый банк содержит проигрыватель, второй — стандартный заголовок
ROM. Стрелки влево и вправо листают экраны, круговое переключение включено.
Поддерживается до 254 экранов (ROM до 4 MiB).

Берутся только файлы с расширением `.scr` и размером 6912 байт; остальные
файлы не попадают в ROM и перечисляются в отчёте. Экран преобразуется в
совместимый с SMS режим TMS9918 Graphics II: исходные атрибуты Spectrum
переносятся в таблицу цветов VDP. `FLASH` в первой версии не анимируется.
Значения Spectrum-палитры и правило `BRIGHT` взяты из
[`scrview.c`](https://github.com/antivir88/scrview/blob/main/scrview.c).
У TMS9918 палитра фиксирована, поэтому для каждого из этих цветов выбирается
ближайший доступный аппаратный цвет.

Нужен `sjasmplus`, тот же ассемблер, которым собираются ROM монитора и
скомпилированные BASIC-программы.
